## 1. Facebook — versi cerita

```
Dah lama menyampah dengan takwim sekolah bentuk PDF / hantar dalam WhatsApp —
bila nak cari tarikh sesuatu program, memang tak jumpa. 😮‍💨

Jadi aku buat sendiri: Takwim Digital.

• Data duduk terus dalam Google Calendar — guru guna Calendar macam biasa,
  takwim ikut sendiri
• Cuti umum Malaysia auto masuk (termasuk cuti bergerak macam Raya/Deepavali)
• Guru boleh tambah aktiviti, admin kawal siapa boleh edit
• Boleh cetak takwim bulanan (grid) untuk fail panitia
• Ada kategori "Cuti Sekolah" khas untuk admin

Yang penting: PERCUMA. Guna akaun Google sekolah sendiri. Takda server nak bayar,
takda database nak jaga.

Korang pun boleh pasang untuk sekolah masing-masing. Aku dah siapkan panduan
salin-tampal — 15 minit siap, tak perlu tau coding langsung. Ada butang "Salin"
sekali klik.

👉 https://syazwanbmw-dev.github.io/takwim-digital/

Open source (MIT). Kalau ada GPB / guru data yang rajin, cubalah. Ambil je,
ubah suai ikut sekolah korang.
```
