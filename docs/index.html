📅 Pasang Takwim Digital untuk sekolah anda

Untuk cikgu — tak perlu tahu coding. Salin kod, tampal ke Google Apps Script. ± 15 minit.

PERCUMA · guna akaun Google anda sendiri

Takwim Digital ialah papan pemuka kalendar aktiviti sekolah. Ia berjalan di Google Apps Script dan menyimpan data terus dalam Google Calendar — tiada pangkalan data, tiada pelayan, tiada bayaran.

Panduan ini menggunakan cara paling mudah: salin & tampal. Butang Salin di bawah mengambil kod terkini terus dari repo, jadi anda sentiasa dapat versi terbaharu.

Apa yang anda perlukan

  • Akaun Google — elok guna akaun sekolah (Workspace / GAFE / DELIMa). Akaun ini menjadi Super Admin sistem anda.
  • Satu Google Calendar untuk takwim sekolah (sedia ada atau buat baharu — Langkah 1).
  • Lebih kurang 15 minit.

1Sediakan Google Calendar

Jika sekolah sudah ada kalendar khas takwim, langkau langkah ini.

  1. Buka calendar.google.com.
  2. Sebelah kiri → Other calendars → tanda + → Create new calendar.
  3. Nama: contoh "Takwim SK Contoh" → Create calendar.

Kita perlukan Calendar ID kalendar ini nanti (Langkah 7).

2Buka Google Apps Script

  1. Pergi ke script.google.com.
  2. Klik New project (kiri atas).
  3. Projek baharu terbuka dengan satu fail bernama Code.gs.

3Masukkan kod bahagian 1 — Code.gs

  1. Klik dalam kotak kod Code.gs → Ctrl+A → Delete (kosongkan).
  2. Klik butang Salin di bawah.
  3. Kembali ke Apps Script, klik dalam Code.gs → Ctrl+V (tampal).
Sedang muat kod… Buka fail di GitHub →
Nama fail di GitHub ialah Code.js, di Apps Script Code.gs — tidak mengapa, isinya sama. Jangan ubah apa-apa; tampal seadanya.

4Masukkan kod bahagian 2 — Index.html

  1. Panel Files (kiri) → tanda + → HTML.
  2. Namakan fail: Index — huruf I besar, jangan taip .html. Tekan Enter.
  3. Fail terbuka dengan kandungan contoh → Ctrl+A → Delete.
  4. Klik Salin di bawah → kembali → klik dalam Index.html → Ctrl+V.
Sedang muat kod… Buka fail di GitHub →

5Tetapkan zon waktu — appsscript.json

  1. Klik ⚙️ Project Settings (panel kiri).
  2. Tandakan "Show 'appsscript.json' manifest file in editor".
  3. Kembali ke Editor (< >) → buka appsscript.json → Ctrl+A → Delete.
  4. Klik Salin di bawah → tampal → Ctrl+S (simpan).
{
  "timeZone": "Asia/Kuala_Lumpur",
  "dependencies": {},
  "exceptionLogging": "STACKDRIVER",
  "runtimeVersion": "V8"
}

6Deploy (terbitkan) sebagai laman web

  1. Kanan atas → Deploy → New deployment.
  2. Ikon ⚙️ di sebelah "Select type" → pilih Web app.
  3. Isi:
    • Description: v1
    • Execute as: Me
    • Who has access:
      • Akaun sekolah (Workspace) → Anyone within [nama sekolah]
      • Gmail biasa → Anyone with a Google Account (anda luluskan setiap guru — Langkah 9)
  4. Klik Deploy. Google minta kebenaran:
    • Authorize access → pilih akaun anda
    • Skrin "Google hasn't verified this app" → Advanced → Go to … (unsafe) → Allow
    • ⚠️ Ini normal — anda yang pasang skrip ini sendiri.
  5. Salin URL Web app yang dipaparkan — inilah alamat sistem takwim anda.

7Dapatkan Calendar ID

  1. Buka calendar.google.com.
  2. Sebelah kiri → kalendar takwim anda → ⋮ → Settings and sharing.
  3. Skrol ke Integrate calendar → salin Calendar ID (rupa abc123@group.calendar.google.com; kalendar utama = alamat e-mel anda).

8Siapkan sistem (Setup Wizard)

  1. Buka URL Web app (dari Langkah 6).
  2. Borang Setup muncul. Isi:
MedanContoh / nota
Nama Sistem / AplikasiTakwim SK Contoh
Nama OrganisasiSK Contoh, Kuala Lumpur
Nama PendekTakwim (label menu)
Google Calendar IDtampal nilai dari Langkah 7
E-mel Super Admine-mel akaun yang anda guna sekarang — mesti sama
Warna Tema / Footer / URL Ikonpilihan
  1. Klik Test Connection. Jika hijau → Install.
  2. Muat semula halaman → anda masuk sebagai Super Admin. ✅

9Jemput guru lain

  1. Guru lain buka URL yang sama → daftar (nama, jawatan, unit). Tiada kata laluan, tiada OTP.
  2. Akaun mereka berstatus "menunggu kelulusan".
  3. Anda → System Settings → Users → Luluskan + pilih peranan:
PerananBoleh buat
adminsemua — termasuk urus pengguna & kategori "Cuti Sekolah"
editortambah / ubah aktiviti takwim
viewerlihat sahaja

Bila ada versi baharu — cara kemas kini

  1. Buka projek Apps Script anda.
  2. Salin semula Code.gs dan Index.html (butang di Langkah 3 & 4), ganti isi lama sepenuhnya.
  3. Ctrl+S.
  4. Deploy → Manage deployments → ✏️ edit → Version: New version → Deploy.

URL Web app anda kekal sama selepas kemas kini.

Masalah biasa

MasalahSebab & penyelesaian
"Sistem belum dipasang"Setup Wizard belum siap. Buka URL Web app, bukan editor Apps Script.
"Calendar ID tidak dapat diakses"Calendar ID salah, atau akaun anda tiada akses ke kalendar itu. Semak Langkah 7.
"E-mel Super Admin mesti sama…"E-mel dalam borang ≠ akaun yang deploy. Guna akaun yang sama.
Skrin "Google hasn't verified this app"Normal untuk skrip sendiri. Advanced → Go to … (unsafe) → Allow.
Guru lain → "You need access"Who has access terlalu ketat. Manage deployments → edit → tukar akses → New version → Deploy.
